## 📱 About Matscape

Matscape is a powerful, feature-rich matrix calculator designed for students, engineers, mathematicians, and anyone who works with matrices. Built with modern Android architecture, it offers an intuitive interface combined with robust mathematical capabilities.

### 🌟 Why Choose Matscape?

- **🔄 Multiple Matrix Support**: Work with matrices A through Z simultaneously
- **📊 Complex Expressions**: Handle nested expressions with unlimited depth
- **⚡ Real-time Results**: Instant calculation with live feedback
- **🎯 Precision**: High-accuracy floating-point arithmetic
- **📱 Modern UI**: Material Design with dark/light theme support
- **🔒 Privacy First**: 100% offline - no data collection or internet required

## ✨ Core Features

### 🔢 **Matrix Operations Arsenal**

#### Basic Operations

- **➕ Addition & Subtraction**: Compatible dimension matrices
- **✖️ Multiplication**: Full matrix multiplication with dimension validation

- **🔢 Scalar Operations**: Multiply/divide matrices by scalars

- **🔱 Determinant**: Calculate determinants for square matrices

## 📊 **Matrix Operations Reference**

### 🔢 **Supported Operations**

| Operation           | Syntax   | Example      | Requirements         |
| ------------------- | -------- | ------------ | -------------------- |
| **Addition**        | `A + B`  | `A + B`      | Same dimensions      |
| **Subtraction**     | `A - B`  | `A - B`      | Same dimensions      |
| **Multiplication**  | `A • B`  | `A • B`      | A.cols = B.rows      |
| **Division**        | `A / B`  | `A / B`      | B must be invertible |
| **Scalar Multiply** | `k • A`  | `3 • A`      | Any scalar k         |
| **Power**           | `A^n`    | `A^2`, `A^3` | Square matrix        |
| **Transpose**       | `A^T`    | `A^T`        | Any matrix           |
| **Determinant**     | `\|A\|`  | `det(A)`     | Square matrix        |
| **Inverse**         | `A^-1`   | `A^-1`       | Non-singular         |
| **Trace**           | `tr(A)`  | `trc(A)`     | Square matrix        |
| **Adjoint**         | `adj(A)` | `adj(A)`     | Square matrix        |
| **Minors**          | `M(A)`   | `min(A)`     | Square, ≥2×2         |
| **Cofactors**       | `C(A)`   | `cof(A)`     | Square, ≥2×2         |

### 🚨 **Error Handling**

The app provides comprehensive error detection:

- **❌ Dimension Mismatch**: Clear messages for incompatible operations
- **🚫 Singular Matrices**: Detection of non-invertible matrices
- **⚠️ Invalid Operations**: Prevention of impossible calculations
- **💡 Helpful Hints**: Suggestions for fixing common errors

## 🚀 **Getting Started**

### 📋 **Prerequisites**

- **📱 Android Device**: API level 29+ (Android 9.0+)
- **💾 Storage**: 15MB free space
- **🔋 Battery**: Standard app usage

### 📥 **Installation**

#### From Google Play Store (Recommended)

1. 🔗 Visit [Google Play Store](https://play.google.com/store/apps/details?id=com.ByteMechanics.matscape)
2. 📱 Tap "Install"
3. 🚀 Launch and start calculating!

#### From Source Code

```bash
# Clone the repository
git clone https://github.com/Thre4dripper/Matscape-AndroidApp.git

# Open in Android Studio
cd Matscape-AndroidApp
./gradlew assembleDebug

# Install on device
adb install app/build/outputs/apk/debug/app-debug.apk
```

### 📖 **Quick Start Guide**

#### 1️⃣ **Creating Your First Matrix**

```
1. 📱 Launch Matscape
2. ➕ Tap the "+" button to add a matrix
3. 📝 Edit matrix values using the numpad
4. ✅ Save your matrix
```

#### 2️⃣ **Performing Calculations**

```
1. ➕ Add a result card
2. 🔤 Type your expression (e.g., "A + B")
3. ⚡ See instant results
4. 📋 Copy or convert results to new matrices
```

#### 3️⃣ **Advanced Features**

```
1. ⚙️ Access Settings via navigation drawer
2. 🎨 Toggle dark/light theme
3. 📏 Set default matrix dimensions
4. 🔧 Customize matrix types
```
